# **GROMACS-LS: Local Stress and Elasticity Calculations from MD Simulations**

GROMACS-LS is a heavily modified version of GROMACS (<https://www.gromacs.org/>) designed to compute the local stress and elasticity tensors in 1-, 2-, or 3-dimensions from equilibrium molecular dynamics (MD) simulations. Most of the local stress/elasticity calculations in GROMACS-LS are performed by the MDStress library (<https://bitbucket.org/mdstresslib/mdstress-library>).
